# LlamaIndex Experiments

This repository contains examples and experiments using [LlamaIndex](https://www.llamaindex.ai/) to build LLM applications.

## Examples Included
- **VectorStoreIndex**: Basic document ingestion and vector querying.
- **SummaryIndex**: Sequential document indexing and querying.
- **TreeIndex**: Hierarchical indexing.
- **Custom Node Parser**: Example of how to build a custom chunker by subclassing `NodeParser`.
- **LLM Integrations**: Examples using Google GenAI and Groq.
